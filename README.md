# Portofolio Daffa Nailul Huda

Website portofolio responsif menggunakan HTML, CSS, dan JavaScript vanilla.

## Cara menjalankan
1. Ekstrak `portfolio-daffa.zip`.
2. Buka folder `portfolio-daffa` di Visual Studio Code.
3. Buka file `index.html` langsung di browser, atau jalankan dengan ekstensi Live Server.

## Isi folder
- `index.html` — struktur halaman website.
- `style.css` — tampilan, responsif, animasi, dan tema.
- `script.js` — navigasi, animasi teks, filter proyek, modal detail, salin email, form kontak.
- `assets/profile.jpeg` — foto profil yang diambil dari CV yang diberikan.
- `assets/Daffa-CV.pdf` — salinan CV sumber.

## Bagian yang bisa disesuaikan
- Data pendidikan, pengalaman, dan keterampilan: edit bagian terkait di `index.html`.
- Foto profil: ganti `assets/profile.jpeg` dengan foto baru, lalu samakan nama file pada tag `<img>`.
- Kartu proyek: ubah judul, deskripsi, kategori (`data-category`), tag, dan detail proyek.
- Kontak: ubah email/nomor telepon pada `index.html` dan konstanta `emailAddress` di `script.js`.
- Persentase skill adalah indikator visual contoh, bukan hasil tes kemampuan.

Form kontak membuka aplikasi email melalui `mailto:` dan tidak mengirim pesan otomatis. Website ini tidak membutuhkan server atau database.
